# benchmark/scripts/dev/ - dataset builders and release packaging

These scripts built the benchmark inputs in `benchmark/data/` and package the archived record for
Zenodo. None are needed to build, verify or use the tool, and none feed the published numbers
directly: every figure and table derives from `benchmark/runs/RUNS.tsv`.

| script | role |
|---|---|
| `build_capped_genomes.py` | the size ladder: subsamples the full-genus alignments to fixed taxon counts (`benchmark/data/protein/n*_g__*/`) |
| `build_1thread_genomes.py` | the six-taxon sets used for the single-thread cells (`benchmark/data/protein/1Thread_*/`) |
| `build_dna_datasets.sh` | the twelve small simulated nucleotide sets (`benchmark/data/dna/dna_n*/`) with AliSim |
| `build_complexity_datasets.sh` | the fourteen large simulated nucleotide sets, regenerated byte-identically from each set's `PROVENANCE.md` |
| `dna_cpu_reference.sh` | CPU reference runs for the DNA sets (`benchmark/runs/dna_cpu_reference/`) |
| `build_zenodo_bundle.sh` | stages only the alignments too large for GitHub, with `zenodo_assets/install_into_repo.sh` |
| `build_zenodo_record.sh` | stages the complete archived record (inputs, measurements, code) for the Zenodo deposit |
| `zenodo_upload.py` | creates or updates the Zenodo deposit from the staged record |

Provenance of every dataset: [`benchmark/data/README.md`](../../data/README.md) and the
`PROVENANCE.md` beside each alignment.
