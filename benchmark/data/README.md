# Input data

The benchmarks read everything from here. Git holds the provenance (metadata tables, `PROVENANCE.md`
files, checksums, guide trees); the data files themselves are on Zenodo,
**doi:10.5281/zenodo.22942159** (one archive per folder, named after its path), and
`benchmark/scripts/fetch_benchmark_data.sh` puts them in place. Figures and tables do not need them.

| folder | what it holds | Zenodo archive | size |
|---|---|---|---|
| `genomes/` | 435 source genomes (MAGs), one directory per genus; `genome_metadata.tsv`, `study_citations.tsv` in git | `benchmark_data_genomes.tar.gz` | 262 MB |
| `protein/` | 45 amino-acid alignments (35 run in the benchmark); `PROVENANCE.md` and `tree_qc.tsv` in git | `benchmark_data_protein.tar.gz` | 55 MB |
| `dna/` | 26 simulated nucleotide alignments; recipes, guide trees and `CHECKSUMS.sha256` in git, simulator logs with the alignments | `benchmark_data_dna.tar.gz` | 755 MB |

```bash
bash benchmark/scripts/fetch_benchmark_data.sh alignments   # protein + dna: what the harness needs
bash benchmark/scripts/fetch_benchmark_data.sh genomes      # only to audit how the alignments were built
python3 benchmark/scripts/verify_data.py                     # md5 of every genome, every alignment tip, every DNA checksum
```

The DOI resolves once the record is published with the paper. The 14 large nucleotide sets can also
be regenerated from their `PROVENANCE.md` (below).

## `genomes/` — the primary data

`genomes/g__<genus>/<stable_genome_id>.fna`: the 435 metagenome-assembled genomes behind every
amino-acid alignment, from 8 published studies and 23 host species. `genome_metadata.tsv` has one
row per genome (42 columns): study, source file, BioProject, BioSample, assembly accession, host,
sampling metadata, GTDB-Tk taxonomy, CheckM2 quality, md5, and which alignments carry it.
`PROVENANCE.md` explains every column, the identifier scheme, and the eight studies with their
papers and deposits; `study_citations.tsv` holds those eight citations (paper, DOI, deposit) as a
table, which Supplementary Data 0 joins to the metadata so every MAG carries its source and citation. A genome's file name is also its tip label in every alignment.

## `protein/` — the amino-acid benchmark inputs

One directory per dataset, each holding `concat_alignment.faa` (concatenated marker-gene
alignment, FASTA, tips = genome ids). Four families, all cut from the same 14 full-genus alignments
each listed with its recipe (the `concat_alignment.faa` files come from Zenodo):

| family | n | what it is | built by |
|---|---|---|---|
| `g__<genus>/` | 14 | the full genus (10–66 taxa, 99k–245k columns); also carries `tree_qc.tsv` | upstream marker-gene pipeline (Prodigal, DIAMOND, MAFFT, concatenation) |
| `n<NN>_g__<genus>/` | 12 | the size sweep: 12 distinct taxon counts, 4 to 30 | `benchmark/scripts/dev/build_capped_genomes.py` |
| `1Thread_g__<genus>_n6/` | 14 | 6-taxon subsets for the single-thread comparison | `benchmark/scripts/dev/build_1thread_genomes.py` |
| `p_lc_n<NN>_L<cols>/` | 5 | column-subsampled low-complexity sets | `benchmark/scripts/dev/build_complexity_datasets.sh` |

Every subset is a seeded, deterministic subsample of its parent and names it in its own
`PROVENANCE.md`. `protein/README.md` tabulates taxa and columns per dataset.

## `dna/` — the nucleotide benchmark inputs

One directory per dataset, each holding `aln.phy` (PHYLIP) plus `PROVENANCE.md` (taxa, sites,
guide tree, model string, seed and the literal AliSim command), the guide tree and the simulator
log. All are simulated with IQ-TREE 3.1.3 AliSim under the model in `TRUE_MODEL.txt`, so the true
model is known. The `aln.phy` files come from Zenodo; the 14 `dna_pt_*`, `dna_hc_*`, `dna_ux_*`
sets (24–382 MB) can also be regenerated byte-identically:

```bash
bash benchmark/scripts/dev/build_complexity_datasets.sh && sha256sum -c benchmark/data/dna/CHECKSUMS.sha256
```

`dna/README.md` has the details.

## Verifying

`python3 benchmark/scripts/verify_data.py` (add `--quick` to skip the checksum reads). A folder that has
not been downloaded is reported as such, not failed.

## Not here

`examples/data/` holds three tiny demonstration alignments (8 taxa, ~3.5k columns) cut from
`protein/`; they belong to the worked example, not the benchmark.
