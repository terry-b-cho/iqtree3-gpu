# Code of Conduct

> This project follows the
> [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/);
> the summary below is binding in all project spaces.

## Summary

Be respectful and constructive. Harassment, personal attacks and discriminatory language are not
acceptable in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour to the maintainers, Byeongyeon Cho (<byeongyeon_cho@hms.harvard.edu>)
or Aleksandar D. Kostic (<Aleksandar.Kostic@joslin.harvard.edu>). Reports will be handled
confidentially.
