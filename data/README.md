# Input data

Everything the benchmarks read lives here. Nothing in this directory depends on anything outside
this repository, and `python3 scripts/verify_data.py` proves the directory is complete and intact.

```
data/
  genomes/     435 raw source genomes (MAGs), one directory per bacterial genus     ~830 MB, Git LFS
  protein/     35 amino-acid alignments built from those genomes (the protein benchmark)   ~130 MB
  dna/         26 simulated nucleotide alignments (the DNA benchmark)                  12 tracked, 14 regenerable
```

## `genomes/` — the primary data

`genomes/g__<genus>/<stable_genome_id>.fna`: the 435 metagenome-assembled genomes behind every
amino-acid alignment, from 8 published studies and 23 host species. `genome_metadata.tsv` has one
row per genome (42 columns): study, source file, BioProject, BioSample, assembly accession, host,
sampling metadata, GTDB-Tk taxonomy, CheckM2 quality, md5, and which alignments carry it.
`PROVENANCE.md` explains every column, the identifier scheme, and the eight studies with their
papers and deposits. A genome's file name is also its tip label in every alignment.

## `protein/` — the amino-acid benchmark inputs

One directory per dataset, each holding `concat_alignment.faa` (concatenated marker-gene
alignment, FASTA, tips = genome ids). Four families, all cut from the same 14 full-genus alignments
and all ordinary tracked files:

| family | n | what it is | built by |
|---|---|---|---|
| `g__<genus>/` | 14 | the full genus (10–66 taxa, 99k–245k columns); also carries `tree_qc.tsv` | upstream marker-gene pipeline (Prodigal, DIAMOND, MAFFT, concatenation) |
| `n<NN>_g__<genus>/` | 12 | the size sweep: 12 distinct taxon counts, 4 to 30 | `scripts/dev/build_capped_genomes.py` |
| `1Thread_g__<genus>_n6/` | 14 | 6-taxon subsets for the single-thread comparison | `scripts/dev/build_1thread_genomes.py` |
| `p_lc_n<NN>_L<cols>/` | 5 | column-subsampled low-complexity sets | `scripts/dev/build_complexity_datasets.sh` |

Every subset is a seeded, deterministic subsample of its parent and names it in its own
`PROVENANCE.md`. `protein/README.md` tabulates taxa and columns per dataset.

## `dna/` — the nucleotide benchmark inputs

One directory per dataset, each holding `aln.phy` (PHYLIP) plus `PROVENANCE.md` (taxa, sites,
guide tree, model string, seed and the literal AliSim command), the guide tree and the simulator
log. All are simulated with IQ-TREE 3.1.3 AliSim under the model in `TRUE_MODEL.txt`, so the true
model is known. The 12 `dna_n<NN>` sets (0.8–6.3 MB) are tracked; the 14 `dna_pt_*`, `dna_hc_*`,
`dna_ux_*` sets (24–382 MB) exceed GitHub's file limit and are regenerated byte-identically:

```bash
bash scripts/dev/build_complexity_datasets.sh && sha256sum -c data/dna/CHECKSUMS.sha256
```

`dna/README.md` has the details.

## Verifying

```bash
python3 scripts/verify_data.py          # md5 of every genome, every alignment tip, every DNA checksum
python3 scripts/verify_data.py --quick  # the same without reading the large files
```

## Not here

`examples/data/` holds three tiny demonstration alignments (8 taxa, ~3.5k columns) cut from
`protein/`; they belong to the worked example, not the benchmark.
